A page with embedded orgchat

This is an ordinary HTML page. The chat button in the bottom-right corner is loaded by a single script, with the chat itself isolated in an iframe.

Try it

Open the chat, switch channels, and send a message. Close it to return to the launcher. Press Escape while inside the chat to close it as well. Unread channels appear as a count on the launcher.

Start the mock server on port 3001 and the frontend with pnpm dev. The mock server generates occasional messages and presence changes. Open the full chat in another tab to see messages synchronize.

Embed code

<script src="https://chat.example.org/widget.js" defer></script>

Replace the domain with the location of your chat deployment. No Svelte code or chat styles are required on the host page.

The host page stays usable

The popup is non-modal. You can continue interacting with this page while it is open, and the collapsed iframe only occupies the chat button.
